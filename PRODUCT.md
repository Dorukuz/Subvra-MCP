# Subvra — Product Register

## What Subvra Is
App Store screenshot generation SaaS. Users describe their app screenshot in a prompt, select Apple device targets (iPhone 6.7", 6.5" legacy, iPad 12.9", iPad 11"), and receive production-quality App Store screenshots generated by GPT Image 2, processed to exact Apple resolutions via Sharp.

## Core Value Proposition
- **Speed**: Prompt to screenshot in under a minute
- **Precision**: Exact App Store Connect pixel resolutions for every Apple device
- **Transparency**: 1 credit = 1 screenshot, no hidden fees
- **Team-ready**: Pooled credits, per-seat pricing, org admin

## Monetization
- 3-day free trial with 2 credits
- Monthly subscriptions: Starter (25 credits) / Pro (80) / Team (200 + seats)
- One-time top-up packs: 25 / 75 / 200 credits
- Auto top-up when credits hit 0 (if subscription active + saved payment method)
- Credits expire at end of billing period, no rollover

## User Personas
1. **Solo indie developer** — needs 5–20 screenshots per release cycle. Cost-sensitive. Values transparency.
2. **Small app studio** (3–8 people) — needs team pooling, shared history. Values workflow speed.
3. **Agency / marketing team** — high volume, batch generation. Values brand consistency and export quality.

## Competitive Positioning
Wedge vs Screenshot Lab, AppMockup, ScreenMagic, StoreShots, AppDrift:
- Credit-transparent (no opaque "plans")
- Apple-resolution-native (not approximations)
- Team pools with seat economics (not per-user silos)
- GPT Image 2 quality (not template-based)
- Self-hosted infrastructure trust (no vendor lock-in)

## UX Principles
1. No processing without auth + active credits — strict gating
2. Draft persistence: anonymous users can submit, draft saves, auth redirects, resume after login
3. Credits are the primary affordance — always visible, always honest
4. Error states surface OpenAI refusals gracefully with reason
5. Admin operations (credit adjustment, subscription override) require explicit reason

## Technical Identity
- Infra-trust brand: deep blue palette, technical grid motifs, monospace accents for data
- Swiss-like hierarchy: clear, rational, no decoration for decoration's sake
- Precision instrument narrative: calibrated, machined, exact
